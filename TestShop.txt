1) เตรียมสภาพแวดล้อม
--------------------------------------------------------------------------------
- รัน: npm run dev
- ตรวจ .env มีอย่างน้อย:
    DATABASE_URL
    NEXTAUTH_URL / NEXTAUTH_SECRET (แอดมิน)
    STRIPE_SECRET_KEY / STRIPE_WEBHOOK_SECRET (ถ้าทดสอบ Stripe)
    RESEND_API_KEY / RESEND_FROM_EMAIL (ถ้าทดสอบอีเมลจริง; ไม่มีก็จะ log ใน console)
- Seed ข้อมูล demo (ถ้ายังไม่มีสินค้า):
    npm run shop:seed
- รีสตาร์ท dev server หลังเปลี่ยน schema / Prisma

บัญชีแอดมิน: เข้า /admins ตามระบบเดิมของเว็บ
หน้าลูกค้าตัวอย่าง: /th/shop  หรือ /en/shop


2) แคตตาล็อก / สินค้า (Public)
--------------------------------------------------------------------------------
[ ] เปิด /th/shop เห็นรายการสินค้า
[ ] ค้นหา (?q=) แล้วผลลัพธ์ตรง
[ ] เรียง: ล่าสุด / ราคาต่ำ→สูง / สูง→ต่ำ / ความนิยม (popularity)
[ ] Filter: New arrivals (?filter=new), Bestsellers, Featured
[ ] Pagination เปลี่ยนหน้าได้เมื่อสินค้า > 12
[ ] เปิดหมวด /th/shop/category/[slug]
[ ] เปิด PDP /th/product/[slug]
[ ] เลือกสีเป็นวงกลม (swatch) ไม่ใช่ข้อความอย่างเดียว
[ ] เปลี่ยนสีแล้วรูปแกลเลอรีเปลี่ยนตามสี
[ ] เลือกไซส์ / จำนวน / ดูสต็อก
[ ] กด Add to cart สำเร็จ
[ ] กด Wishlist (หัวใจ) สำเร็จ
[ ] เห็น Sale / -N% / New / Bestseller ตามที่ตั้งในแอดมิน
[ ] เห็น Additional information / Size guide (ถ้ามีข้อมูล)
[ ] Related products แสดงด้านล่าง


3) ตะกร้า / Mini-cart
--------------------------------------------------------------------------------
[ ] ไอคอนตะกร้าโชว์จำนวน
[ ] Mini-cart เปิดแล้วมีลิงก์ไป Cart / Checkout
[ ] /th/cart แก้จำนวน / ลบสินค้าได้
[ ] สินค้าหมดสต็อกแล้วเพิ่มไม่ได้


4) Checkout — Stripe
--------------------------------------------------------------------------------
[ ] /th/checkout กรอกที่อยู่ครบ
[ ] เลือก Pay with Stripe
[ ] (ถ้ามีคูปอง) ใส่โค้ดแล้วส่วนลดคำนวณถูกต้อง
[ ] ไปหน้า Stripe Checkout สำเร็จ
[ ] ชำระสำเร็จ → /checkout/success แสดงเลขออเดอร์
[ ] Webhook / success ทำให้สถานะเป็น PAID
[ ] สต็อกลดลงหลัง PAID
[ ] อีเมลยืนยันออเดอร์ถูกส่ง (หรือเห็นใน console)


5) Checkout — โอนธนาคาร (ไม่มีอัปโหลดสลิป)
--------------------------------------------------------------------------------
[ ] เลือก Bank transfer ที่ checkout
[ ] ไปหน้า /checkout/bank?order=... เห็นบัญชี / QR / ยอด
[ ] ไม่มีฟอร์มอัปโหลดสลิปบนหน้านี้
[ ] ข้อความแจ้งให้โอนแล้วรอทีมงานยืนยัน
[ ] ออเดอร์สถานะ AWAITING_TRANSFER
[ ] อีเมลรอโอนถูกส่ง (หรือ console)
[ ] แอดมินเปลี่ยนสถานะเป็น PAID → สต็อกลด + อีเมลยืนยัน
หมายเหตุ: ระบบนี้ไม่รับอัปโหลดสลิปบนเว็บแล้ว
         การยืนยันโอนทำโดยแอดมินใน /admins/content/shop/orders
